# UCE 开发计划表

本文档用于记录 Ultra Confrontation Engine 的开发计划、待定想法和阶段目标。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 待定 | 想法已经记录，但暂时不进入开发 |
| 规划中 | 方向确定，等待拆分任务 |
| 开发中 | 当前正在制作 |
| 待验证 | 功能完成，等待测试或体验确认 |
| 已完成 | 已实现并通过确认 |
| 暂停 | 暂时停止，等待条件成熟 |

## 待定计划

| 序号 | 计划名称 | 计划说明 | 触发时机 | 状态 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 001 | 公开赛事看板 | 让其他人不下载 UCE，也能通过网页查看赛事进程。初步方案是 GitHub Pages + 公开 JSON 数据。 | S1 名单、审核流程、模拟对战流程稳定后 | 待定 | 不公开官方备注、本地路径、训练细节和敏感提交数据 |
| 002 | UCG 专属平台化 | UCE 早期服务于 AI 模拟对抗；后期逐步升级为 UCG 专属平台，集成 UC 体系下的卡牌、PVP、PVE、MUGEN 格斗、MOBA 等内容。 | 多个赛季与基础游戏模块稳定后 | 待定 | 平台化不影响 UCE 当前引擎定位，长期对外可逐步转为 UCG 平台 |
| 003 | P2P 与局域网联机 | UCE 升级到 0.7.0 后开放 P2P 和局域网联机，本地创建房间并共享给加入玩家。 | 0.7.0 阶段 | 待定 | 服务器线上功能需要更长期规划 |
