# UCE 授权结构

本文档记录 UCE / UCG 的授权拆分方式。

## 当前原则

UCE 需要同时满足三个目标：

1. 引擎本体保持开源。
2. 创作者可以使用 UCE 制作并导出自己的游戏，且可以自由盈利。
3. UCG 官方内容、素材、赛事服务和未来内购不被代码开源协议误伤。

因此，本项目不采用“所有内容一个协议”的做法。

## 推荐拆分

| 内容 | 授权策略 |
| --- | --- |
| UCE 源代码 | `GPL-3.0-or-later` |
| UCE 编辑器 / 平台 | `GPL-3.0-or-later` |
| UCE 导出 Runtime | 后续单独拆分，倾向 `MPL-2.0`、`LGPL-3.0` 或 `Apache-2.0` |
| 创作者导出的游戏内容 | 归创作者自行决定 |
| UCG 官方游戏内容 | 单独商业授权或自定义 EULA |
| Logo、立绘、音乐、角色设定 | 默认保留权利，除非明确声明 |
| 参赛提交内容 | 遵守 `SUBMISSION_TERMS.md` |
| 服务端、账号、内购、云训练 | 可单独闭源和商业化 |

## Runtime 注意事项

如果未来导出的游戏直接打包 GPL 授权的 UCE Runtime，创作者的游戏可能会受到 GPL 传播条款影响。

为了保证创作者可以自由盈利，正式导出功能稳定前，应当把 Runtime 从 GPL 编辑器中拆分出来，并使用更适合游戏分发的许可证。

## 官方游戏商业化

UCE 代码开源不等于 UCG 官方游戏内容开源。

官方游戏可以通过以下方式盈利：

- 官方内容包
- 角色包
- 皮肤和 DLC
- 赛事服务
- 云训练服务
- 联机服务
- 账号和服务器功能

这些内容应当和 GPL 源代码保持清楚边界。
