## プロジェクト紹介

Ultra Confrontation は、『Undertale』のファンゲームの発展をもとに設計された統括型の開発プロジェクトです。現時点では、このプロジェクトを二つの部分に分けています。

一つ目は Ultra Confrontation Game、略称 UCG です。ここにはカードゲーム、シミュレーション大会対戦、MOBA 系、全方向型 Mugen 格闘、PVP、PVE などが含まれます。また、これらの種類だけに限定されるものではありません。

二つ目は Ultra Confrontation Engine、略称 UCE です。UCE は、上記すべての内容を支えるためのエンジンです。

このエンジン自体は、ファンゲームの多様性を広げるためのものです。ファン作品は RPG や SRPG などの形式だけに限らず、別の方向にも発展できます。

参加者や多くの友人の協力により、UCE エンジンは AI シミュレーション対戦大会への全面的な適応をすでに完了しています。現在の内容は主にこのモジュールの磨き込みを中心に進め、`v0.3.0` で AI トレーニングを実装する予定です。PPO ニューラルネットワークシミュレーションアルゴリズムを基盤として、エンジンの利用者は自分の AU 専用の AI エージェントや、UCG 大会に参加するための AI データユニット集を作成できるようになります。

## ゲーム拡張の方向性

ゲーム拡張については、現在いくつかの種類のゲームに向けたインターフェース接続とフレームワークの予約を行っています。

- カードゲーム：カード殺系ゲームの開発フレームワークをすでに予約しており、今後並行して制作できます。
- 格闘ゲーム：Mugen エンジンの一部機能を取り込んでいますが、現時点ではまだ適応していません。
- MOBA：テンプレートは一時的に作成していますが、まずは計画を優先するため、今後の課題です。
- PVP / PVE：種類は未定ですが、大会需要や後期の手動プレイを考慮し、追加設計があります。
- オンラインモード：UCE エンジンが `v0.7.0` にアップグレードされた後、P2P と LAN 接続を開放します。プレイヤーはローカルで部屋を作成し、参加するプレイヤーにネットワークを共有できます。サーバー型オンライン機能の開発には、さらに時間がかかる可能性があります。

現在の設計に基づき、UCE エンジン開発段階では UC の S1 シーズン「起源」がすでに開始されています。このシーズンは、まだ全言語コミュニティのファン創作者に向けて開放されていません。現時点では、中国語コミュニティを対象とした試験的な開発と大会シミュレーションのみを行っています。

とはいえ、このプロジェクトは私自身のファン創作への空虚な幻想から生まれたものでもあります。実のところ、曲作りに少し麻痺してきたので、気ままにプロジェクトを開発してみているだけです。

本プログラムは Rust エコシステムをもとに制作されており、GPL オープンソースライセンスを使用しています。興味のある方は自由にダウンロードして使用できます。

それでは、あなたの生活が楽しいものでありますように。そして、私たちの未来のファン創作に限界がありませんように。

## 技術スタック

- フロントエンド：React 19、TypeScript、Vite
- デスクトップシェル：Tauri 2
- 状態管理と国際化：Zustand、i18next
- バックエンドエンジン：`src-tauri/src` 配下の Rust コマンドとロジック
- ゲームデータ：`assets` と `src-tauri/assets` 配下の JSON ファイル

## プロジェクト構成

- `src/`：React アプリ、ページ、共通 UI コンポーネント、ストア、スタイル
- `src-tauri/src/`：Rust 戦闘エンジン、ローダー、ルール、モデル、Tauri コマンド
- `assets/`：編集可能なソースゲームデータ
- `src-tauri/assets/`：Tauri バックエンドが実行時に使用するデータ
- `replays/`：アプリによって生成されるローカルリプレイファイル

## 開発

依存関係をインストール：

```powershell
npm install
```

ゲームデータを同期：

```powershell
npm run sync:assets
```

ゲームデータが同期されているか確認：

```powershell
npm run check:assets
```

Web フロントエンドを実行：

```powershell
npm run dev
```

Tauri アプリを実行：

```powershell
npm run tauri dev
```

フロントエンドをビルド：

```powershell
npm run build
```

Rust バックエンドを確認：

```powershell
cd src-tauri
cargo check
```
